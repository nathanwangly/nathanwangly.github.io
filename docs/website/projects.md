# Projects

This is guidance for site work, not approved project copy. Separate the current implementation from design ideas that are still open.

## Current implementation

- `projects.md` renders the project listing from `_data/projects.yml`. Each entry currently shows a tag, optional status, name, description, and links where available.
- Park&Ride links to a tool page in `_projects/carpark_tracker.md` and a longer post. Offload links to a project hosted outside this site. A project hosted elsewhere may have its own presentation.
- The listing uses `assets/css/projects.css`. Project summaries and any corresponding detail page need to stay in sync.

## Direction under consideration

- Nathan has expressed interest in project cards with visual icons or imagery so the section is easier to scan than a purely text-based list. No particular card design or image set has been approved.

## Open choices

- Whether each future project needs a detail page, post, external link, or only a listing entry depends on the project. Preserve published URLs when changing that structure.
