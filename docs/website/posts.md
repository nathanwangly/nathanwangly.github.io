# Posts

This is guidance for site work, not approved post copy. Nathan writes published wording himself unless he expressly permits a specific change.

## Current implementation

- Posts live in `_posts/` and use `_layouts/post.html` with `assets/css/post.css`. The layout shows a title, date, optional update date, reading time, and description before the body.
- The repository currently contains a longer Park&Ride project write-up, linked from the Projects listing and the tool page. There is no separate posts index in the current site.

## Confirmed direction

- The site should offer a place for projects or writing Nathan chooses to share. No publishing schedule or required post format has been established.

## Open choices

- A dedicated posts index and any broader editorial or visual format remain undecided.
